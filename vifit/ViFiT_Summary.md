# ViFiT 论文总结

> **ViFiT: Reconstructing Vision Trajectories from IMU and Wi-Fi Fine Time Measurements**
> 发表于：**ISACom '23**（MobiCom Workshop），2023 年 10 月，马德里
> 作者：Bryan Bo Cao et al.（Stony Brook University / Rutgers University / Georgia State University）

---

## 一、核心问题

现有的视频追踪系统有两个痛点：

1. **视觉失效场景**：光线差、遮挡、目标离开视野时，纯视觉追踪器失效
2. **网络传输瓶颈**：将完整视频流传到远端服务器处理，带宽占用极高

**ViFiT 的解决思路：** 当摄像头只有**第 1 帧**可用时，用手机的 IMU（加速度、陀螺、磁力计）和 WiFi FTM 测距数据，**重建缺失帧中的行人边界框轨迹**，从而只需传输极少数帧就能完成追踪。

---

## 二、任务定义

```
已知输入：
  ├── Tc0  ∈ R^(1×5)     第 1 帧视觉边界框（仅有一帧）
  ├── Ti   ∈ R^(WL×9)   完整窗口的 IMU 数据（加速度+陀螺+磁力计）
  └── Tf   ∈ R^(WL×2)   完整窗口的 FTM 测距数据（range, std）

重建目标：
  └── Tc'  ∈ R^(WL×5)   窗口内全部缺失帧的边界框  [x, y, d, w, h]

评估设置：
  - 窗口长度 WL = 30 帧，步长 WS = 29
  - IoU > 0.5 视为重建质量合格
```

---

## 三、模型架构（ViFiT）

整体为 **三编码器 + 单解码器** 的 Transformer 架构：

```
          ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
  Tc0 ───►│   Vision    │   │    IMU      │   │    FTM      │
  Ti  ───►│  Encoder    │   │  Encoder    │   │  Encoder    │
  Tf  ───►│  (B=4 层)   │   │  (B=4 层)   │   │  (B=4 层)   │
          └──────┬──────┘   └──────┬──────┘   └──────┬──────┘
                 │  X'c            │  X'i            │  X'f
                 └────────────────►┼◄────────────────┘
                                   │ Concat(X'c, X'i, X'f)
                                   ▼
                          ┌─────────────────┐
                          │  Vision Decoder  │
                          │ Proj → GELU →   │
                          │ LayerNorm → Pred │
                          └────────┬────────┘
                                   │
                                  Tc'  (WL × 5)
```

### 编码器（三个结构相同）

每个 Encoder 处理各自模态，4 个 Transformer Block 串联：

```
输入 Tm (WL × Dm)
  → Proj: Linear(Dm → Hdim=72)       # 升维投影
  → LayerNorm
  → PositionalEncoding                # 注入时序位置信息
  → B=4 × TransformerBlock:
      Multi-Head Self-Attention       # h=4 头, dk=dv=72
      Proj + LayerNorm                # 残差连接
      FFN(72 → 144 → 72) + LayerNorm  # GELU 激活
输出 X'm (WL × Hdim)
```

| 模态 | 输入维度 Dm | 编码器输出 |
|------|-----------|-----------|
| Vision (Tc0) | 5 | WL × 72 |
| IMU (Ti) | 9 | WL × 72 |
| FTM (Tf) | 2 | WL × 72 |

### 解码器（Vision Decoder）

```
X'fused = Concat(X'c, X'i, X'f)    # WL × 216
  → Proj(216 → 72)
  → GELU
  → LayerNorm
  → Pred(72 → 5)
输出 Tc' (WL × 5)                   # 重建的完整边界框序列
```

> 关键设计：**去掉了残差连接**，使解码器完全依赖多模态融合特征，而非从视觉编码器旁路获取信息。

## 四、训练设置

### 损失函数（双损失）

```
L = L_MSE + L_DIoU
```

| 损失 | 公式 | 作用 |
|------|------|------|
| MSE | ∑(Tc - Tc')² | 点级别坐标回归 |
| DIoU | 1 - IoU + ρ²(中心距) / s² | 边界框级别几何约束，同时约束位置和大小 |

### 超参数

| 参数 | 值 |
|------|----|
| 隐层维度 Hdim | 72 |
| 注意力头数 h | 4 |
| Transformer Block 层数 B | 4 |
| 前馈层维度 Fdim | 144 |
| 激活函数 | GELU |
| 模型参数量 | **0.15 M**（极轻量） |

## 五、评估指标

### 已有指标

| 指标 | 含义 |
|------|------|
| IoU | 预测框与真值框的交并比，>0.5 为合格 |
| AP@.5 | IoU>0.5 时的平均精度（mAP） |
| AP@.1 | IoU>0.1 时的平均精度 |

### 新提出指标：MRF / MRFR

**MRF（Minimum Required Frames，最少所需帧数）**

> 在一段视频流中，方法持续产生 IoU > 0.5 的合格重建所**最少需要查询的真实帧数**。
> MRF 越小 = 帧利用率越高 = 需要传输的视频帧越少。

```
MRFR = MRF / W    （归一化为窗口比例，便于跨视频比较）
```

**直觉理解：** MRF=37.75 表示在 58 个窗口中，平均只有 37.75 个窗口需要查一帧真实画面就能连续重建出高质量轨迹。

## 六、对比基线

| 方法 | 类型 | 说明 |
|------|------|------|
| BC（Broadcasting） | 传统 | 将第 1 帧直接广播复制到所有缺失帧 |
| PDR（Pedestrian Dead Reckoning） | 传统+规则 | IMU 积分估计位置，NED 坐标系转图像坐标 |
| KF（Kalman Filter） | 传统 | 卡尔曼滤波估计边界框状态 |
| X-Translator | 深度学习（LSTM）| ViTag 中的跨模态 LSTM 编码-解码器，此处用手机→视觉方向 |
| **ViFiT（本文）** | 深度学习（Transformer）| — |

---

## 七、实验结果

### 主要结果（4 个户外场景均值，WL=30）

| 方法 | MRF ↓ | MRFR ↓ | 说明 |
|------|-------|--------|------|
| ALL（总窗口数） | 58 | 1.00 | 上界（每帧都用） |
| BC | 56.75 | 0.98 | 几乎没有效果 |
| X-Translator | 56.75 | 0.98 | LSTM 表现同 BC |
| PDR | 56.5 | 0.97 | 轻微改善 |
| KF | 53 | 0.91 | 有效但有限 |
| **ViFiT（本文）** | **37.75** | **0.65** | 超越第二名 15.25 |

**关键数字：ViFiT 只需 2.24% 的视频帧（≈97.76% 帧可缺失）就能重建出 IoU=0.55 的合格轨迹。**

### 与视觉检测器对比

| 模型 | AP@.5 | 帧利用率 | 模态 | 参数量 |
|------|-------|---------|------|--------|
| YOLOv5m | 0.91 | 100% | 纯视觉 | 21.2 M |
| YOLOv5n | 0.90 | 100% | 纯视觉 | 1.9 M |
| ViFiT-10F | **0.82** | **2.25%** | 视觉+IMU+FTM | 0.15 M |
| ViFiT-30F | 0.56 | **2.24%** | 视觉+IMU+FTM | 0.15 M |

> ViFiT-10F 以 0.15M 参数、2.25% 帧率，达到 YOLOv5 的 90% AP 水准。

### 消融实验（传感器特征）

全特征（A+G+M+F）组合效果最好：

| 特征组合 | IoU | AP@.5 | AP@.1 |
|---------|-----|-------|-------|
| 单个特征（A/G/M/F） | 较低 | 较低 | 较低 |
| A+G+M（无 FTM） | — | 0.47 附近 | — |
| **A+G+M+F（全部）** | **0.50** | **0.47** | **0.82** |

结论：FTM 在与 IMU 联合使用时有显著增益，单独使用效果有限。

## 八、网络传输节省效果

| 传输内容 | 数据量 |
|---------|--------|
| 原始完整视频流 | 100% |
| 使用 ViFiT 后（仅传 2.24% 帧 + 手机传感器数据） | **< 1%** |

> 实测传输数据量节省 **99% 以上**（IMU + FTM 数据远小于视频帧，手机传感器数据几乎可以忽略不计）。

---

## 九、连续重建轨迹统计

- 平均连续重建长度：**45.01 帧**（≈4.5 秒 @ 30fps）
- 最大连续重建长度：**87 帧**（≈2.9 秒 @ 30fps）
- 每 1.55 个窗口才需要查询一次真实帧

## 十、本文定位与 ViFi 系列工作对比

| 论文 | 会议 | 任务 | 核心模型 |
|------|------|------|---------|
| **Vi-Fi**（2022） | IPSN | 跨模态**身份关联**（视觉↔手机） | LSTM + Attention |
| **ViTag**（2022） | SECON | 跨模态**轨迹互译** + 关联 | LSTM 编码-解码器（X-Translator） |
| **ViFiT**（2023）| ISACom | 从手机数据**重建视觉轨迹**（帧压缩） | Transformer 三编码器 |
| **OOSTraj**（2024） | CVPR | 从带噪传感器预测**视野外**目标轨迹 | Transformer + 相机矩阵估计器 |

ViFiT 是 Vi-Fi 系列的第三步，核心创新在于：
1. 将任务从"关联"升级为"重建"
2. 用 Transformer 替换 LSTM，更好建模长时序依赖
3. 引入新指标 MRF/MRFR，从系统视角量化帧压缩效益
